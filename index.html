Política RLS ausente no Supabase

O banco está bloqueando a exclusão

Acesse o SQL Editor do seu projeto no Supabase e execute o comando abaixo: 

DROP POLICY IF EXISTS "allow_delete_anon" ON public.chamados;
CREATE POLICY "allow_delete_anon"
ON public.chamados
FOR DELETE
TO anon
USING (true);

Após executar, tente excluir novamente.
